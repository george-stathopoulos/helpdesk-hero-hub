# Helpdesk Hero documentation

Guides, answers and troubleshooting for Helpdesk Hero, with screenshots of every screen. The same guides are on the website's [help center](https://george-stathopoulos.github.io/helpdesk-hero/docs/), and you can try everything in the [live demo](https://george-stathopoulos.github.io/helpdesk-hero/demo/).

## Start here

- [Getting started](getting-started.md): install the hub, run the setup guide and connect your first customer site.
- [How it works](how-it-works.md): how the hub and customer sites connect, and what travels between them.

## Using the hub

- [Inbox and tickets](inbox.md): tickets from every site, with diagnostics, replies, tags and ratings.
- [Site access](site-access.md): one-click login without passwords, support sessions, more time, troubleshooting mode and the activity log.
- [Connecting sites](sites.md): connection codes, per-site policies, bulk changes and connection checks.
- [Policies and templates](policies.md): your rules for customer sites, and templates to apply them in bulk.
- [Overview and statistics](overview.md): categories, recurring issues and response times.
- [Settings](settings.md): team details, ticket tags, backup and restore.
- [Helpdesk Hero Pro](pro.md): analytics, PDF reports, white label, ratings, supporters and AI triage.
